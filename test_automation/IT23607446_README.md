# Test Automation for Chat Translator

**Student ID: IT23607446**

**Repository:** [https://github.com/Lakshi0917/IT23607446.git](https://github.com/Lakshi0917/IT23607446.git)

This project provides automated testing for the Chat Translator web application using Playwright. It reads test cases from an Excel file, interacts with the frontend to perform translations, and records the results back into the Excel file.

## Features

- Automated testing of Singlish to Sinhala translation
- Excel-based test case management
- Configurable wait times, retries, and typing delays
- Headless or visible browser modes
- Real-time result saving
- Support for different UI layouts (chat and non-chat modes)

## Prerequisites

- Python 3.8 or higher
- Playwright for Python
- openpyxl for Excel file handling

## Installation

1. Install Python dependencies:

   ```bash
   pip install playwright openpyxl
   ```

2. Install Playwright browsers:
   ```bash
   playwright install
   ```

## Usage

Run the test automation script with the following command:

```bash
python test_automation.py [options]
```

### Command Line Options

- `--excel`: Path to the Excel file containing test cases (default: `test_automation/Assignment 1 - Test cases.xlsx`)
- `--sheet`: Name of the sheet in the Excel file (default: " Test cases")
- `--header-row`: Row number containing headers (default: auto-detected)
- `--input-col`: Column name for input text (default: auto-detected from candidates like "Singlish", "Input")
- `--expected-col`: Column name for expected output (default: auto-detected from candidates like "Sinhala", "Expected Output")
- `--actual-col`: Column name for actual output (default: auto-detected or "Actual output")
- `--status-col`: Column name for test status (default: auto-detected or "Status")
- `--url`: URL of the frontend to test (default: `https://www.pixelssuite.com/chat-translator`)
- `--output`: Path to save the output Excel file (default: same as input)
- `--save-every`: Save results every N test cases (default: 0, save at end)
- `--headless`: Run in headless mode (no browser UI)
- `--wait-ms`: Wait time after input before checking output (default: 5000ms)
- `--retries`: Number of retries to get output (default: 8)
- `--retry-wait-ms`: Wait time between retries (default: 1000ms)
- `--type-delay-ms`: Delay between typing characters (default: 30ms)
- `--timeout-ms`: Timeout for page operations (default: 60000ms)
- `--slow-mo-ms`: Slow motion delay for browser actions (default: 0ms)
- `--keep-open`: Keep browser open after tests (for debugging)

### Example Usage

Run tests with default settings:

```bash
python test_automation.py
```

Run in headless mode with custom Excel file:

```bash
python test_automation.py --headless --excel "path/to/test_cases.xlsx"
```

Run with visible browser and slow motion for debugging:

```bash
python test_automation.py --slow-mo-ms 200 --type-delay-ms 80 --save-every 1 --keep-open
```

## Excel File Format

The Excel file should have columns for:

- **Input**: The Singlish text to translate
- **Expected Output**: The expected Sinhala translation
- **Actual Output**: (Will be filled by the script) The actual output from the frontend
- **Status**: (Will be filled by the script) PASS/FAIL/COLLECTED/UI Error

The script automatically detects column headers based on common names.

## How It Works

1. Loads test cases from the specified Excel file
2. Launches a Chromium browser using Playwright
3. Navigates to the chat translator URL
4. For each test case:
   - Enters the input text into the textarea
   - Waits for the translation to appear
   - Compares the actual output with the expected output
   - Records the result in the Excel file
5. Saves the updated Excel file

## Troubleshooting

- **Browser not launching**: Ensure Playwright browsers are installed with `playwright install`
- **Element not found**: The script tries to locate UI elements automatically, but if the frontend changes, it may fail
- **Timeout errors**: Increase `--timeout-ms` or `--wait-ms` values
- **Excel file issues**: Ensure the file is not open in another application when running the script
